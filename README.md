# Immortal Wedding — Frontend

React + Vite invitation app for Immortal Web. Hosts configure invitations; guests open `/i/{slug}`.

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- React Router 7

## Run locally

Start the [backend API](https://github.com/Vikas-a1/immortal_wedding_backend) on port `8000`, then:

```bash
npm install
npm run dev
```

Open http://localhost:5173

Vite proxies `/api` and `/uploads` to the backend.
